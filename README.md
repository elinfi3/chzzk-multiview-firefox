# 치지직 멀티뷰어 (CHZZK Multi-Viewer for Firefox)

치지직(CHZZK) 생방송을 단일 브라우저 탭에서 다분할 화면으로 동시에 시청할 수 있는 파이어폭스(Firefox) 전용 확장 프로그램입니다.

---

## 주요 기능

* **HLS 초저지연 고화질 재생**: 네이버 공식 라이브 스트림을 직접 연결하여 군더더기 없는 순수 비디오 플레이어 구동
* **자유로운 화면 배치 & 마그넷 스냅**: 드래그 앤 드롭 이동, 리사이즈 모드 및 $1/n$ 등분/모서리 자동 흡착
* **화면 비율 프리셋 & 커스텀 저장**: `1x1`, `2x1`, `1x2`, `2x2`, `1+n` 기본 레이아웃 및 사용자 정의 화면 배치 저장/불러오기
* **스마트 채팅 & 오디오 동기화**: 활성 화면 클릭 시 채팅 실시간 연동 및 방송별 동시 청취/음소거 독립 제어
* **최근 시청 채널 기록**: 시청 채널 자동 저장, 5개 단위 페이징 및 상·하단 접기 제어
* **사이드바 접기/펼치기**: 우측 설정 및 채팅 사이드바를 숨겨 화면 전체를 비디오 영역으로 확장


---

## 개인정보 보호 (Privacy)

* 본 확장 프로그램은 사용자의 어떠한 개인정보나 시청 기록도 외부 서버로 전송하지 않습니다.
* 모든 설정값 및 최근 시청 채널 기록은 사용자의 로컬 브라우저 저장소(`browser.storage.local`)에만 보관됩니다.
